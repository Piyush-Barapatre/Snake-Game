# Snake-Game
A classic Snake game developed using Java. The player controls a snake that grows longer as it eats food, with the goal of achieving the highest score without hitting the walls or itself.

🚀 Features
Classic snake gameplay

Real-time keyboard controls

Score tracking

Game over screen

Simple and clean GUI (using Swing / JavaFX if applicable)

Adjustable speed or grid size (if implemented)

🛠️ Technologies Used
Java

Swing (or JavaFX) for GUI

Object-Oriented Programming concepts
